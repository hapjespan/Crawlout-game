# assets/

- `src/`: bronbestanden (GLB, PNG, .blend). Placeholders: Quaternius Universal Animation Library en basiskarakters (CC0), Gobkit Nature Kit (CC0).
- `dist/`: uitvoer van `tools/asset-cli` (meshopt-GLB, KTX2, LODs, animatietextures, manifest.json). Gecommit, zodat de client zonder buildstap laadt.

De technische brief voor assets staat in `docs/spelfundament-v0.1.md` sectie 9. De asset-cli valideert ertegen.
