- 0.16.0 (content-x, meer Dwellers-content: robots, vangnet, training, turret-netwerk, uitrusting in tiers, held-passieven; schemawijzigingen ter bevestiging door de architect). Gemeten balans is er niet: alle getallen zijn startwaarde, geen balans. De replay-fixtures en match-length/mirror-tests falen op de VERSION-bump en de AI-wijzigingen; de sim-agent neemt ze opnieuw op en stemt de AI af. Schema en loader:
  - `Role` krijgt `technician` en `robot` (achteraan, dus ROLES-indices 0 tot 2 ongewijzigd). Refine: role robot hoort bij bodyType robot en andersom.
  - `Loadout`: `producedAt` (gebouw-id waar een robot nieuw gebouwd wordt; verplicht bij bodyType robot, verboden bij human; LoadoutData.producedAt, -1 = omscholen in de werkplaats), `repair { repairRateHpPerS, rangeM, seekRangeM, targets[building|robot] }` (LoadoutData.repair: milliHpPerTick, rangeU, seekRangeU, targets; `REPAIR_TARGETS`; omrekening `perSecondToMilliPerTick` in units.ts) en `siege { vsBuildingsDamagePct, buildingsFirst }` (LoadoutData.siege: vsBuildingsPermille, buildingsFirst). repair en siege alleen voor robots.
  - `Faction.safetyNet` is nu een strict `SafetyNet`: `action` een enum (nu `radiobaken_instroom`), bij die actie verplicht `intervalS`, `maxArrivals` en `loadoutId` (FactionData.safetyNet: intervalTicks, maxArrivals, loadoutId). `Faction.robotRules { robotsPerTechnician, technicianRoles[], robotPenaltyPct }` (FactionData.robotRules: robotsPerTechnician, technicianRoles als ROLES-indices, robotPenaltyPermille), verplicht bij bodyType robot in bodyTypes.
  - `Building.network { requiresTech, radiusM, damagePctPerTurret, maxDamagePct }` alleen bij provides turret (BuildingData.network: requiresTech, radiusU, damagePermillePerTurret, maxDamagePermille; null zonder).
  - `EffectStat` krijgt `researchCostPct` (achteraan; Pct dus promille; doel `alle`). `Hero.passives[]` (Effect, zelfde semantiek als perk-effecten; HeroData.passives).
  - Nieuw bestand `data/training.json` met schema `Training` (id, faction, special, building, scrapCost, scrapCostStep, trainS, trainSStep, pointsPerRun, maxPoints, prereqTech); `RawGameData.training`, `readDataDir` leest het, `GameData.training: TrainingProgramData[]` (trainTicks, trainTicksStep). Gekozen boven een velden-uitbreiding van tech: tech is een bitset van 32 (sim MAX_TECHS) en een SPECIAL-punt is een teller per letter, geen eenmalige unlock.
  - `AiScript.robots { sequence[], fromS, max }` optioneel (AiScriptData.robots: sequence, fromTicks, max; null zonder).
  - Geen nieuwe waarde in `Provides`: provides is een bitmasker van 8 bits in de sim (config.ts, intIn 0..0xff) en alle acht bits zijn bezet; de robotfabriek heeft `provides: []` en de koppeling loopt via `Loadout.producedAt`.
  - Buiten packages/data (minimaal, zodat alles blijft compileren en laden): apps/client/src/game/content.ts geeft `training` door aan RawGameData; apps/client/src/main.ts toont technician en robot als "geen rol" (de HUD-Role is de protocol-Role met drie waarden); packages/sim/test/helpers.ts kreeg compacte footprints voor `robotfabriek` en `turret_laser`.
